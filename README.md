# ML Zoomcamp 2026 — Homeworks

## Setup
- Install uv: https://docs.astral.sh/uv/getting-started/installation/
- (optional) Initialize dependencies: `uv sync`

Each exercise has its own README with details.

## Run

```bash
uv run 01-intro/homework_01.py
uv run 02-regression/homework_02.py
uv run 03-classification/homework_03.py
uv run 04-evaluation/homework_04.py
uv run 05-deployment/homework_05.py
uv run 06-trees/homework_06.py
uv run 08-deep-learning/homework_08.py
uv run 09-serverless/homework_09.py
uv run 10-kubernetes/homework_10.py
```
